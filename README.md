# Abby
Accounting Software

Abby provides a helpful solution to accounting problems this application targets small businesses, self employed and sole traders to help do basic bookkeeping, scanning invoices, vat calculations as well as provide core api calls from hmrc to commit tax returns for making tax digital (returns every quarter), vat returns and more features.
